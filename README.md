# Freedom Knight ⚔️

Videojuego 2D de acción y plataformas desarrollado con el motor **Godot Engine 4**.

---

## 🛠️ Requisitos del Entorno de Desarrollo

Para ejecutar y compilar este proyecto desde un clon limpio se requiere:

* **Sistema Operativo:** macOS 12+, Windows 10/11 o Linux (Ubuntu 22.04+).
* **Motor:** [Godot Engine 4.x (Standard / Forward+)](https://godotengine.org/download).
* **Git:** Versión 2.30 o superior.

---

## 🚀 Pasos para Ejecutar desde un Clon Limpio

Sigue estos pasos en orden para levantar el proyecto en tu máquina local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/EsaulTellez/Freedom-Knight.git
   cd Freedom-Knight
   ```

2. **Abrir el proyecto en Godot Engine:**
   * Abre la aplicación **Godot Engine 4**.
   * En el gestor de proyectos (*Project Manager*), haz clic en el botón **Importar** (*Import*).
   * Haz clic en **Explorar** (*Browse*) y navega hasta la carpeta del repositorio, seleccionando el archivo `freedom-knight/project.godot`.
   * Haz clic en **Importar y editar** (*Import & Edit*).

3. **Ejecutar el juego:**
   * Una vez abierto el editor, presiona la tecla **F5** (o el botón de reproducción ▶️ *Play* en la esquina superior derecha).
   * La escena principal se compilará y se abrirá la ventana del juego inmediatamente.

---

## 🎮 Controles Predeterminados

* **Movimiento:** Teclas `A` / `D` o Flechas Izquierda / Derecha.
* **Salto / Arriba:** Tecla `W` o Flecha Arriba.
* **Agacharse / Abajo:** Tecla `S` o Flecha Abajo.
* **Ataque con Espada:** Botón de ataque en interfaz / Tecla asignada.
* **Pausa:** Menú de pausa integrado.
